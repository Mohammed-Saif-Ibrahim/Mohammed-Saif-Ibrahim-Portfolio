# Mohammed Saif Ibrahim — Portfolio

My personal developer portfolio, designed and built to showcase my projects, technical skills, and experience as a software developer.

**Live:** [mohammedsaifibrahim.com](https://mohammedsaifibrahim.com)

## Tech Stack

* **Next.js 14** — React framework and application architecture
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Styling and responsive design
* **Vercel** — Production deployment

## Features

* Dark, terminal-inspired visual design
* Responsive design for desktop and mobile
* Animated hero section and interactive UI elements
* Project showcase with individual case studies
* Technical skills and experience sections
* Contact and social links
* SEO metadata and Open Graph configuration
* Production deployment with Vercel

## Project Structure

```text
app/            # Next.js application routes and pages
components/     # Reusable UI components
lib/            # Project data and utilities
public/         # Static assets
```

## Deployment

The portfolio is deployed in production using Vercel.
